# OrynthLabs Docs

This folder is the onboarding entry point for engineers joining the project.

Start here:

1. `PRODUCT.md` for what the product is and why — read this first
2. `TECH_STACK.md` for the system architecture and implementation choices
3. `BUILD_PLAN.md` for the roadmap from idea to alpha and beyond

The goal of these docs is to make the project understandable without needing tribal knowledge.
