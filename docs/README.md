# Orynth ProductLab Docs

This folder is the onboarding entry point for engineers joining the project.

Start here:

1. `TECH_STACK.md` for the system architecture and implementation choices
2. `BUILD_PLAN.md` for the roadmap from idea to alpha and beyond
3. `SIGNING_BOUNDARY.md` for the security rules around Solana signing

The goal of these docs is to make the project understandable without needing tribal knowledge.
